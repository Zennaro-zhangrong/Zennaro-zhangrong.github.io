传感器数值一跳一跳，直接送进控制器会让输出抖动。把它“变平滑”很容易，但怎样保证真正要看的变化没有被抹掉？这就是数字滤波器设计要解决的问题。

本文从零开始，不要求读者先学完信号处理课程。读完应能把“保留 50 Hz 以下变化、压低 100 Hz 以上噪声”写成指标，设计 FIR 与 IIR 两种方案，用程序检查频响、延迟和边界，并知道什么时候换用移动平均、中值或陷波器。

学习方法：第一遍只读第 1～3 节，亲手算一次采样频率和一阶递推；第二遍先猜第 5、6 节哪种方案更省计算，再运行第 7 节代码验证；最后不看正文做第 10 节练习。看懂一条公式后，用“输入什么、输出什么、单位是什么、极限情况怎样”四个问题复述它。

1. 滤波器到底在保留和压低什么

1.1 从一段可想象的传感器数据开始

假设真实温度缓慢变化，测量值还叠加了快速抖动。把测量记作 $x[k]$，滤波结果记作 $y[k]$；$k$ 是第 $k$ 次采样。低通滤波器希望缓慢变化大致通过，快速变化被压低。高通恰好相反；带通保留一段频率；带阻压低一段频率。

这里的“慢”和“快”要用频率表达。1 Hz 表示每秒重复 1 次，100 Hz 表示每秒重复 100 次。滤波器并不知道哪个波形叫“有用信号”，只按设计出的频率响应处理。因此有用信号和噪声如果占据同一频段，单纯低通无法完美分开。

1.2 幅值、相位与延迟都要看

对频率为 $f$ 的正弦输入，线性时不变滤波器的稳态输出仍是该频率的正弦，只是幅值乘上 $\lvert H(f)\rvert$，相位改变 $\angle H(f)$。增益用分贝表示为

$$ G(f)=20\log_{10}\lvert H(f)\rvert\quad(\mathrm{dB}). $$

$0\,\mathrm{dB}$ 表示幅值不变，$-20\,\mathrm{dB}$ 表示幅值约为原来的 $1/10$，$-40\,\mathrm{dB}$ 约为 $1/100$。当控制系统需要及时响应时，不能只看衰减，还必须看滤波造成的相位变化与时延。

2. 先定采样与指标，再谈算法

采样频率 $f_{\mathrm{samp}}$ 单位 Hz，采样间隔 $T_s=1/f_{\mathrm{samp}}$ 单位 s。奈奎斯特频率是 $f_N=f_{\mathrm{samp}}/2$。高于它的输入频率可能折叠到低频，这叫混叠；数字滤波器拿到样本后，通常无法再区分折叠后的噪声与原本的低频信号。因此采样前仍需考虑模拟抗混叠滤波。

下面采用同一份教学需求：

指标 数值 含义
采样频率 $f_{\mathrm{samp}}$ $1000\,\mathrm{Hz}$ 每 $1\,\mathrm{ms}$ 一点
通带边缘 $f_p$ $50\,\mathrm{Hz}$ 0～50 Hz 尽量保留
阻带起点 $f_{\mathrm{stop}}$ $100\,\mathrm{Hz}$ 100～500 Hz 尽量压低
通带允许偏差 $A_p$ $1\,\mathrm{dB}$ 通带增益处于约 $\pm1\,\mathrm{dB}$ 内
阻带最小衰减 $A_s$ $40\,\mathrm{dB}$ 幅值至多约 $1/100$

50～100 Hz 是过渡带：要求滤波器从“保留”逐渐转向“压低”，这里不规定每个频率的精确增益。过渡带越窄、阻带要求越严，通常越需要更高阶数或更大延迟。不要把通带边缘、阻带边缘和某个软件参数中叫作 cutoff 的频率当成同一个值。

设计前还应写下最大允许延迟、处理器每秒可执行的乘加次数、可用内存，以及信号是否要求实时单向处理。离线数据能用的前后向滤波，实时系统通常做不到。

自查：若采样频率为 1000 Hz，700 Hz 的纯正弦采样后会与 300 Hz 的序列混淆；此时在数字域把 300 Hz 压掉，也会压掉真正的 300 Hz 信号。

3. 从差分方程认识 FIR 与 IIR

3.1 FIR：只看当前和过去的输入

一个长度为 $M$ 的 FIR（有限冲激响应）滤波器是

$$ y[k]=\sum_{m=0}^{M-1}h[m]x[k-m]. $$

$h[m]$ 是 $M$ 个系数，也叫抽头；滤波器阶数是 $M-1$。每次计算要保存最近的输入。把只在 $k=0$ 等于 1、其余时刻等于 0 的单位脉冲送入，输出就是有限长的 $h[0],\ldots,h[M-1]$，这解释了名字。有限系数的普通 FIR 没有反馈，数值上不会因为内部极点而自激发散。

最简单的三点移动平均是 $h=[1/3,1/3,1/3]$：

$$ y[k]=\frac{x[k]+x[k-1]+x[k-2]}{3}. $$

若输入是常数 $c$，输出仍是 $c$；若只有一个尖峰，它会被摊到连续三个输出点。这个检查比先背频域公式更容易建立直觉。

3.2 IIR：还使用过去的输出

常见 IIR（无限冲激响应）结构为

$$ y[k]=\sum_{m=0}^{M}b_mx[k-m] -\sum_{n=1}^{N}a_ny[k-n],\qquad a_0=1. $$

输出反馈使一个脉冲的影响可以持续很久；少量系数便可能得到较陡的频率选择，但反馈也使稳定性、系数量化与初值更重要。

例如一阶指数平滑：

$$ y[k]=(1-\alpha)y[k-1]+\alpha x[k],\qquad 0<\alpha\le1. $$

当 $\alpha=1$，直接输出输入；当 $\alpha$ 很小，结果更平滑也更慢。对阶跃输入且 $y[-1]=0$，误差每拍乘 $1-\alpha$，所以

$$ y[k]=1-(1-\alpha)^{k+1}. $$

若从连续时间的一阶低通时间常数 $\tau$ 出发，把每个采样间隔内的输入视为常数，可以选 $\alpha=1-\exp(-T_s/\tau)$。这里 $\tau$ 是秒，不是截止频率；若给定模拟近似 $f_c=1/(2\pi\tau)$，要明确这是由连续模型映射而来，不能不验算就宣称数字域精确达到该 $-3\,\mathrm{dB}$ 点。

4. 先按需求选结构

方法 适合的第一判断 主要代价
线性相位 FIR 波形形状与固定延迟重要 同等频率指标下常需更多抽头
IIR 低通/带通 计算量和内存紧张 相位通常不线性，需检查稳定性
移动平均 要快速实现基础平滑 频率选择不灵活，可能压低有用频率
指数平滑 只需很低成本的缓慢跟踪 过渡不够陡，存在滞后
中值滤波 偶发孤立尖峰 非线性，会改变细节，不能用普通频响描述
陷波器 已知窄带干扰，如固定频率嗡声 频率漂移时效果变差

FIR 可以设计出精确线性相位，此时所有通带频率的群延迟相同；IIR 通常能以较低阶达到相近幅度指标。这是常见取舍，不是说“所有 FIR 都线性相位”或“IIR 一定不稳定”。MathWorks 的 FIR 设计说明和 IIR 设计说明分别展示了这些方法与代价。

5. FIR 怎么设计：从理想低通到可实现系数

5.1 理想低通为何需要截断

把频率写成数字角频率 $\omega=2\pi f/f_{\mathrm{samp}}$，单位 rad/样本。理想低通在 $\lvert\omega\rvert<\omega_c$ 增益为 1，其他频率为 0。它的冲激响应由逆离散时间傅里叶变换得到：

$$ h_{\mathrm{ideal}}[n]= \begin{cases} \dfrac{\sin(\omega_c n)}{\pi n},&n\ne0,\\ \dfrac{\omega_c}{\pi},&n=0. \end{cases} $$

这条序列向前后无限延伸，不能直接在实时程序中实现。取中心附近有限个样本，再乘一个渐变的窗函数减轻硬截断的波纹，得到有限长 FIR。若系数关于中心对称，即 $h[m]=h[M-1-m]$，且 $M$ 为奇数，就有固定群延迟 $(M-1)/2$ 个采样间隔。这个过程、以及等波纹和最小二乘等其他 FIR 设计法，可参见 MathWorks FIR Filter Design。

5.2 用一组指标求一个可检验的设计

本例以 $f_c=(f_p+f_{\mathrm{stop}})/2=75\,\mathrm{Hz}$ 作为窗函数法的设计中心。采用 Kaiser 窗，目标偏差先设为 $44\,\mathrm{dB}$，过渡宽度是 $50\,\mathrm{Hz}$，相对奈奎斯特频率为 $50/500=0.1$。SciPy 的 kaiserord 会给出一个估计抽头数和窗参数；这是估计，最终必须按实际通带和阻带重新验收。SciPy kaiserord 文档。

在本文所用的 SciPy 1.17.1 中，把抽头数调整为奇数后得到 $M=53$。因此线性相位延迟是 $26$ 个样本，即 $26\,\mathrm{ms}$。对 firwin，这里的 75 Hz cutoff 约是窗函数设计的半幅值点（$-6\,\mathrm{dB}$），并非通带边缘 50 Hz，也并非自动等于 $-3\,\mathrm{dB}$ 点。SciPy firwin 文档。

若 $26\,\mathrm{ms}$ 延迟对电流环过大，就不能只因幅频指标通过而采用此方案。可以放宽指标、提高采样频率后重设计，或评估 IIR；改变采样频率时，所有以 Hz 表示的指标和处理器负担也要一起重算。

6. IIR 怎么设计：模拟原型、数字映射和二阶节

常见 IIR 设计流程是：选择通带与阻带指标 → 选模拟低通原型（Butterworth、Chebyshev、椭圆等）→ 映射成数字滤波器 → 检查实际数字频响。Butterworth 通带平坦；Chebyshev 或椭圆型用允许的纹波换取更陡过渡，具体取舍取决于指标。MathWorks IIR Filter Design。

一种重要映射是双线性变换，把连续系统变量 $s$ 换成

$$ s=\frac{2}{T_s}\frac{1-z^{-1}}{1+z^{-1}}. $$

它能把稳定的模拟左半平面映射到数字单位圆内，但频率关系是非线性的：

$$ \Omega=\frac{2}{T_s}\tan\!\left(\frac{\omega}{2}\right). $$

$\Omega$ 是模拟角频率（rad/s），$\omega$ 是数字角频率（rad/样本）。靠近奈奎斯特频率时，不能把二者简单视为相等；按目标频率做预畸变，或直接用接受 Hz 指标的设计函数。MathWorks 双线性变换说明。

本例让 iirdesign 使用相同的 50 Hz、100 Hz、1 dB、40 dB 指标，选择 Butterworth。输出指定为 sos，即串联的二阶节，每节有一组三个分子和三个分母系数。本文环境得到 4 节；高阶 IIR 若直接展开成一组大多项式系数，有限精度下更容易出现数值问题，SciPy 也建议通用滤波优先用 SOS。SciPy butter 文档。

这里的 IIR 结果没有 FIR 的固定 $26\,\mathrm{ms}$ 群延迟，但“阶数更低”不等于“任何频率都零延迟”。需要在有用频段查看相位或群延迟，并观察阶跃响应。尤其是反馈控制，滤波器相位会改变闭环裕度。

7. 完整 Python 程序：设计、验算、比较

下面是独立可运行程序，需安装 NumPy 和 SciPy。输入是上文频率指标；输出是 FIR 抽头、IIR 二阶节、通带和阻带的测量结果，以及一段合成信号的滤波结果。合成信号仅用于演示；频响验收仍以计算出的频率响应为准。

import numpy as np
from scipy import signal

sample_hz = 1000.0
pass_hz = 50.0
stop_hz = 100.0
pass_limit_db = 1.0
stop_limit_db = 40.0

assert 0 < pass_hz < stop_hz < sample_hz / 2

# Kaiser 窗先估算，再把抽头数变为奇数以获得整数样本群延迟。
width = (stop_hz - pass_hz) / (sample_hz / 2)
numtaps, beta = signal.kaiserord(44.0, width)
if numtaps % 2 == 0:
    numtaps += 1
fir = signal.firwin(
    numtaps, (pass_hz + stop_hz) / 2,
    window=("kaiser", beta), fs=sample_hz,
)

# 根据通带/阻带指标选 Butterworth 阶数，直接输出二阶节。
sos = signal.iirdesign(
    pass_hz, stop_hz,
    gpass=pass_limit_db, gstop=stop_limit_db,
    ftype="butter", output="sos", fs=sample_hz,
)

# 高密度频率网格只用于验收，不用于实时滤波。
freq_hz = np.linspace(0.0, sample_hz / 2, 200_001)
_, fir_response = signal.freqz(fir, worN=freq_hz, fs=sample_hz)
_, iir_response = signal.freqz_sos(sos, worN=freq_hz, fs=sample_hz)

def check_response(name, response):
    magnitude = np.abs(response)
    passband = magnitude[freq_hz <= pass_hz]
    stopband = magnitude[freq_hz >= stop_hz]
    pass_min_db = 20 * np.log10(np.min(passband))
    pass_max_db = 20 * np.log10(np.max(passband))
    stop_max_db = 20 * np.log10(np.max(stopband))
    # 浮点计算在恰好 -1 dB 的边界可能多出 1e-14 dB 的舍入误差。
    tolerance_db = 1e-9
    passed = (pass_min_db >= -pass_limit_db - tolerance_db
              and pass_max_db <= pass_limit_db + tolerance_db
              and stop_max_db <= -stop_limit_db + tolerance_db)
    print(f"{name}: pass=[{pass_min_db:.2f}, {pass_max_db:.2f}] dB, "
          f"stop_max={stop_max_db:.2f} dB, passed={passed}")
    assert passed, f"{name} does not meet the example specifications"

check_response("FIR", fir_response)
check_response("IIR", iir_response)
print(f"FIR taps={numtaps}, delay={(numtaps - 1) / 2 / sample_hz:.3f} s")
print(f"IIR SOS sections={len(sos)}")

# 10 Hz 是想保留的信号，200 Hz 是示例干扰；前段还存在启动瞬态。
time_s = np.arange(1000) / sample_hz
samples = np.sin(2 * np.pi * 10 * time_s)
samples += 0.25 * np.sin(2 * np.pi * 200 * time_s)
fir_output = signal.lfilter(fir, [1.0], samples)
iir_output = signal.sosfilt(sos, samples)
print("last samples:", fir_output[-3:], iir_output[-3:])

在本机 NumPy 2.2.6、SciPy 1.17.1 的密集网格验算中，FIR 通带最小约 $-0.004\,\mathrm{dB}$、最大约 $0.066\,\mathrm{dB}$，阻带最大约 $-44.89\,\mathrm{dB}$；IIR 通带最小 $-1.00\,\mathrm{dB}$、最大约 $0\,\mathrm{dB}$，阻带最大约 $-44.06\,\mathrm{dB}$。两者通过本例幅度要求。这里的数字是网格上的数值检查，不能代替部署前对系数量化、实际输入与时间响应的验证。

想观察现象，可画出 freq_hz 对 $20\log_{10}\lvert H\rvert$ 的曲线，并画 samples、fir_output、iir_output 的时序；纵轴分别标 dB 与采样值。不要只比最后几个样本，也要看启动区间与阶跃输入。

8. 移动平均、中值、陷波与自适应方法怎么用

8.1 移动平均与指数平滑

$M$ 点移动平均系数全为 $1/M$，很容易实现，延迟为 $(M-1)T_s/2$，但它的频率响应有旁瓣和周期性零点。它适合快速去掉某些高频抖动；若有用变化很快，先算出 $M$ 对应的延迟，再决定是否值得。第 3 节的指数平滑只保存一个输出状态，计算更省，但一个一阶低通无法像高阶滤波器那样陡峭地区分 50 Hz 与 100 Hz。

8.2 中值滤波处理孤立尖峰

对奇数长度窗口，把样本排序后取中间值。例如窗口 $[1,1,20,1,1]$ 的中值是 1，同样五点的平均值却为 $4.8$。中值法对这种孤立尖峰有效；但它是非线性方法，不能用前文的 $H(f)$、通带波纹和群延迟公式直接定义其整体效果。连续高频干扰或宽脉冲不一定能被它解决，也可能抹掉真正短促的事件。

8.3 陷波与梳状结构

若干扰集中在已知的 50/60 Hz 或某个机械振动频率，而有用信号主要在其两侧，可以考虑窄带陷波，而不是把该频率以上全部压掉。设计时写清要压掉的中心频率、允许影响的邻近频率和干扰漂移范围；频率会变时，固定陷波可能偏离目标。周期性多频干扰可研究梳状滤波，但它也会在多个频率形成抑制，必须检查是否误伤有用成分。

8.4 卡尔曼等状态估计不是万能平滑按钮

当你有运动或电机的状态方程、测量噪声模型，并需要同时估计多个不可直接测的状态时，可以进一步学卡尔曼滤波或观测器。它们依赖模型与噪声假设，调参和验证比单纯低通复杂。若任务只是去掉固定频段噪声，先完成本篇的频率、延迟和数据检查，再决定是否引入状态估计。

9. 把滤波器放进实际系统前检查什么

  1. 先看采样链：采样率是否稳定、是否有丢样、模拟前端是否防混叠、ADC 码值是否已换算到正确物理量。改变采样率后要重设计系数。
  2. 记录真实数据：分别收集正常变化、突发干扰、阶跃和最差工况。合成正弦通过，只能说明教学示例通过。
  3. 核对启动状态：上电时 FIR 历史样本和 IIR 状态若全为零，输出会有启动过程。需要从首样本初始化还是允许渐入，应由应用决定。
  4. 测实际延迟：FIR 对称系数的 $(M-1)T_s/2$ 是群延迟；IIR 则检查有用频段的相位与阶跃响应。控制环里的额外延迟可能降低稳定裕度。
  5. 考虑数值格式：定点系数取整、累加器位宽、溢出和饱和都会改变理论结果。IIR 的极点位置尤其需要在目标数值格式下重新验算；优先逐节实现 SOS。
  6. 明确实时边界：离线的前后向滤波利用未来样本来抵消相位，不能原样放进逐样本实时中断。中断里用预先算好的系数，不在每拍重新设计滤波器。

排错顺序：先看原始数据和采样时间戳，再看滤波前后的时序，最后看频谱或频响。若“看起来更平滑”却使控制反应变慢，先检查延迟；若输出有巨大尖峰或发散，先检查 IIR 反馈符号、系数顺序和数值溢出。

10. 三道练习，检查是否真正会设计

  1. 概念：1000 Hz 采样的信号里有 600 Hz 干扰。为什么不能只设计一个数字低通，就保证保留全部 400 Hz 以下的真实信号？
  2. 计算：1000 Hz 采样、对称的 53 抽头 FIR，其阶数和固定群延迟是多少？如果控制环最多容忍 5 ms 延迟，它是否合适？
  3. 选择：数据偶尔出现单个极大错误值，但正常信号会有短促的真实脉冲。应先试中值滤波还是低通？怎样防止把真实脉冲当成噪声？

答案与验证方法：

  1. 600 Hz 会混叠到 400 Hz；数字域已无法仅凭这些样本判断 400 Hz 成分的来源。要从采样前抗混叠与采样率入手。
  2. 阶数 $53-1=52$；延迟 $(53-1)/(2\times1000)=0.026\,\mathrm s=26\,\mathrm{ms}$，超过 5 ms 限制，不能仅因幅频指标达标就采用。
  3. 可先用中值法针对孤立错误值做小窗口实验，同时标记真实脉冲样例，量化误删率和脉冲幅度变化。若真实脉冲与错误尖峰形态重合，仅靠局部窗口无法可靠区分，需要额外的物理约束或传感器信息。

下一步练习：把第 7 节的 stop_hz 改为 70 Hz，重新设计并记录抽头数、SOS 节数、验收结果和延迟。先写预测，再运行程序；若性能变化与预测不符，检查你是否把过渡带宽和滤波器阶数联系起来。
